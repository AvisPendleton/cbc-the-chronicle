CBC THE CHRONICLE — WEBSITE FILES

Files:
- index.html: the main newspaper website and submission form.

IMPORTANT: The form endpoint is intentionally a placeholder. Do not publish the site for public submissions until we connect and test a verified form endpoint. This avoids exposing your personal email address in the public website source.

GITHUB PAGES:
1. Create a GitHub account.
2. Create a PUBLIC repository named cbc-the-chronicle.
3. Upload index.html to the top level of the repository.
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.

FORM SETUP:
We will connect the submission form to a verified FormSubmit endpoint in the next setup step. The form currently has a placeholder URL and will not send submissions until that is configured and tested.

PRIVACY:
Collect only information the editorial team needs. Do not ask students to submit sensitive personal information. Submissions should be reviewed by the editorial team before publication.
